飞书能承载的场景清单

编号 分类 主流程 改善机会点 改善点说明
1 To C 用户触达 / 进入 人群分层 将新客、活跃、沉默、高价值、价格敏感等人群拆开运营。
2 To C 用户触达 / 进入 阶段运营 针对拉新、首购、复购、沉默唤醒、流失挽回设计差异化动作。
3 To C 商品详情 / 购买决策 信任表达 用正品、品控、品牌授权、售后保障等信息强化决策信任。
4 To C 商品详情 / 购买决策 信息补全 补齐尺码、材质、场景、洗护、适配人群等高频决策信息。
5 To C 商品详情 / 购买决策 价格证明 明确折扣来源、历史价、到手价、优惠组成，降低价格疑虑。
6 To C 商品详情 / 购买决策 评价结构化 将评价中的尺码、质量、物流、售后等要素拆解，帮助用户快速判断。
7 To C 价格 / 优惠 / 会员权益 规则简化 识别过复杂的优惠门槛和叠加限制，降低用户决策负担。
8 To C 加购 / 下单 / 支付 弃单归因 识别价格、库存、物流、支付、信任等导致加购未转化的原因。
9 To C 加购 / 下单 / 支付 链路监控 对加购、下单、支付、优惠使用等关键节点建立异常监控。
10 To C 加购 / 下单 / 支付 高值挽回 对高价值用户、临门一脚用户设计即时挽回动作。
11 To C 履约 / 物流 延迟预警 在订单可能延迟前提前识别、提醒并准备补偿方案。
12 To C 履约 / 物流 异常看板 将缺货、拦截、退仓、破损、丢件等异常统一可视化。
13 To C 履约 / 物流 承诺一致 让页面承诺、客服口径、物流状态、售后政策保持一致。
14 To C 售后 / 退换货 退因资产化 将退货原因从单次处理沉淀为商品、尺码、质量、履约改进资产。
15 To C 售后 / 退换货 进度透明 让退款、退货、换货状态可视化，减少用户重复咨询。
16 To C 售后 / 退换货 逆向提效 优化取件、质检、入库、退款、换货各环节的内部协同。
17 To C 售后 / 退换货 高频监控 对高退货商品、同类投诉、异常店铺进行持续监控和干预。
18 To C 客服 / VOC 客服前哨 把客服从被动响应变成问题预警入口，提前识别集中爆发问题。
19 To C 客服 / VOC 问题归因 将用户问题归因到商品、价格、物流、售后、页面信息或系统体验。
20 To C 客服 / VOC 舆情预警 对差评、社媒反馈、客服高频词进行趋势识别和预警。
21 To C 客服 / VOC 知识沉淀 把客服话术、问题处理、补偿规则沉淀为可复用知识库。
22 To C 评价 / 体验复盘 体验复盘 将大促、品类、品牌、履约和售后体验按周期复盘。
23 To C 评价 / 体验复盘 评价拆解 从评价中拆出尺码、质量、包装、客服、物流等结构化指标。
24 To C 评价 / 体验复盘 反馈入业务 将用户反馈自动流转给商品、运营、物流、技术等责任方。
25 To C 评价 / 体验复盘 正反复盘 对好评与差评都沉淀可复用做法，避免只处理负反馈。
26 To C 会员 / 复购 复购动因 找出复购来自价格、品牌偏好、上新频率、服务体验还是权益价值。
27 To C 会员 / 复购 沉默诊断 识别用户沉默是因为价格、频次、品类不匹配、体验差还是触达疲劳。
28 To C 会员 / 复购 会员健康度 把售后体验、物流体验、退款次数、客服满意度纳入会员健康评估。
29 To C 会员 / 复购 高值保护 优先识别高价值用户的负面体验，避免一次差体验影响长期价值。
30 To B 品牌 / 商家招募 招商线索沉淀 把展会、BD 拜访、老商家推荐、平台招商等线索统一沉淀和分析，避免线索散落。
31 To B 品牌 / 商家招募 商机阶段管理 明确接触、意向、资质提交、合同推进、试运营等阶段，提升招商转化率。
32 To B 准入 / 资质审核 资质一次性补齐 提前明确营业执照、商标授权、质检报告、行业许可等资料清单，减少反复补件。
33 To B 准入 / 资质审核 审核进度透明 让商家知道当前卡在哪个环节、谁在处理、预计何时完成，降低沟通成本。
34 To B 准入 / 资质审核 合同条款标准化 将扣点、账期、退货责任、活动义务、质保要求沉淀成标准条款和差异审批。
35 To B 选品 / 货盘规划 上新节奏管理 结合大促、换季、库存周期和品牌供货计划，优化商品上新与返场节奏。
36 To B 商品资料 / 上架 商品信息完整度 提升标题、卖点、尺码、材质、成分、洗护、质保等信息的完整性。
37 To B 商品资料 / 上架 素材质量管理 对主图、详情图、模特图、视频、品牌素材建立质量标准和审核流程。
38 To B 商品资料 / 上架 信息复用 将品牌介绍、商品参数、尺码模板、售后说明等沉淀为可复用资产。
39 To B 价格 / 折扣管理 折扣策略复盘 复盘不同折扣深度对转化、毛利、库存消化和品牌心智的影响。
40 To B 供应链 / 备货入仓 来货计划协同 将预约、发货、到仓、质检、入库等节点统一管理，减少临期拥堵。
41 To B 活动 / 资源排期 活动排期可视化 统一管理品牌活动、频道资源、大促会场、直播、站内资源位排期。
42 To B 活动 / 资源排期 活动准备清单 将货品、价格、库存、素材、客服口径、物流承诺等活动前检查项标准化。
43 To B 活动 / 资源排期 大促协同机制 对大促期间的目标、战报、异常、补货、改价、售后问题建立作战机制。
44 To B 售后 / 商家服务 高频问题沉淀 把高频售后问题沉淀为商品改进、页面补充、客服话术和商家整改任务。
45 To B 售后 / 商家服务 商家响应时效 对商家处理工单、补资料、补货、售后举证等响应速度进行管理。
46 To B 对账 / 结算 / 复盘 活动复盘标准化 每场活动复盘销售、库存、价格、流量、售后、利润和商家协同表现。
